# Universal CSV Analytics Platform

## Overview
A Streamlit-based application that automatically analyzes CSV datasets.

## Features
- Upload CSV files
- Automatic Data Cleaning
- Missing Value Analysis
- Statistical Analysis
- Correlation Analysis
- Interactive Visualizations
- Insight Generation
- PDF Report Generation

## Project Structure

CSV-Analytics-App/
├── app.py
├── pages/
├── src/
├── uploads/
├── outputs/
├── requirements.txt
└── README.md

## Technologies Used
- Python
- Pandas
- NumPy
- Plotly
- Streamlit
- Matplotlib
- Seaborn
- ReportLab

## Installation

pip install -r requirements.txt

## Run

streamlit run app.py
